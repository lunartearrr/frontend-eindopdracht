# Atelier Interior Design

Eindopdracht Kennis Create and Code (CMGT, Hogeschool Rotterdam)

Website voor een fictief interieurontwerpbureau, gebouwd met HTML en CSS op basis van de gegeven wireframes.

## Opdracht
Je bouwt de gegeven wireframes na met HTML en CSS. Houd hierbij rekening met de designer notes die in het wireframe staan. Je kiest zelf een onderwerp voor jouw website en voert hierop echte teksten en afbeeldingen over het onderwerp toe (dus geen placeholders), waarvoor je AI mag gebruiken. Kies zelf een stijl met kleuren, afbeeldingen en lettertypes. Let erop dat je voor de mobiele weergave ook het gegeven wireframe gebruikt en de breakpoint van 480px aanhoudt. Je gebruikt in principe alleen de stof uit lessen 1 t/m 8 om de HTML en CSS op te bouwen. Mocht je toch iets anders gebruiken, dan moet je uitleggen waarom.

## Bekijken
Open `index.html` via een lokale server, bijvoorbeeld Live Server in VS Code of de browser preview in WebStorm.

## Structuur
- `index.html`: homepage
- `pages/`: overige pagina's (contact, over ons, tarieven, afspraak, juridische pagina's)
- `css/style.css`: alle styling
- `assets/images/`: afbeeldingen
- `docs/wireframes/`: de gegeven wireframes

## Stijl
- **Lettertype:** Plus Jakarta Sans (Google Fonts)
- **Kleuren:** donkergrijs, lichtgrijs en wit voor een rustige, tijdloze uitstraling
- **Iconen:** Font Awesome

## Bronnen
- Afbeeldingen: [Unsplash](https://unsplash.com)
- Iconen: [Font Awesome](https://fontawesome.com)
- Teksten: Geschreven met hulp van AI
