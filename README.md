# frontend-eindopdracht
Eindopdracht Kennis Create and Code

# Opdracht
Je bouwt de gegeven wireframes na met HTML en CSS met de opgedane kennis uit deze cursus en levert dit op Brightspace in. Houd hierbij rekening
met de designer notes die in het wireframe staan. Je kiest zelf een onderwerp voor jouw website en voert hierop echte teksten en afbeeldingen over
het onderwerp toe (dus geen placeholders), waarvoor je AI mag gebruiken. Kies zelf een stijl met kleuren, afbeeldingen en lettertypes.
Let erop dat je voor de mobiele weergave ook het gegeven wireframe gebruikt en de breakpoint van 480px aanhoudt.
Je gebruikt in principe alleen de stof uit lesFsen 1 t/m 8 om de HTML en CSS op te bouwen. Mocht je toch iets anders gebruiken, dan moet je uitleggen
